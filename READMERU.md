# Larp Components

Редактор планировки фабрики в 3D и симулятор с дискретным временем, построенный на React, Three.js и React Three Fiber. Размещайте станки, конвейеры, роботов, рабочих и паллеты в 3D-сцене, программируйте роботов на JavaScript и запускайте производство в реальном времени.

> **Отказ от ответственности:** Проект не связан с Visual Components. Симулятор и защитные ограждения носят иллюстративный характер и **не** являются сертифицированными промышленными, безопасностными или робототехническими инструментами.

## Быстрый старт

**Требования:** Node.js 20.19+ или 22.12+ (см. `.nvmrc`) и npm.

```bash
npm ci
npm run dev
# http://localhost:5173 (Vite dev server)
```

Пользователи Windows также могут дважды щёлкнуть `start-larp.bat` — скрипт установит зависимости при первом запуске и запустит приложение.

## Скрипты

| Команда | Описание |
|---|---|
| `npm run dev` | Запуск Vite dev-сервера (по умолчанию порт 5173; в документации и тестах используется 4173). |
| `npm run typecheck` | Проверка типов TypeScript через `tsc --noEmit`. |
| `npm run test:unit` | Браузерные тесты симуляции, промптов, навигации, размера проекта, настроек, раскладки, плана этажа, футболок рабочих, производительности и серверного рендеринга UI. |
| `npm run test:signals-browser` | Playwright-тесты редактирования сигнальных портов во вьюпорте. |
| `npm run test:interaction-browser` | Playwright-тесты сигналов питателя, цветных проводов и изменения размера окон мышью и касанием. |
| `npm run test:gizmos-browser` | Проверка 3D-манипуляторов, привязки, отмены и управления сплайном. |
| `npm run test:factory-browser` | Проверка перетаскивания узлов, объединения входов и сборки конвейера. |
| `npm run test:archive-browser` | Playwright-тесты импорта/экспорта `.LCMX` и сохранения/автосохранения. |
| `npm run test:browser` | Четыре основных набора Playwright UI-тестов против dev-сервера на порту 4173. |
| `npm run test:typescript-parity` | Сравнение выбранного состояния симуляции с Git-базой (см. `docs/TYPESCRIPT_OPTIMIZATION.md`). |
| `npm run build` | Production-сборка **плюс** встраивание ресурсов; создаёт `dist/index.html` (автономный, ~10 МБ). |
| `npm run preview` | Локальный запуск production-сборки. |

> Используйте `npm run build`, а не просто `vite build`: встраиватель добавляет упакованные CAD- и worker-ресурсы, необходимые автономному HTML.

### Объединение конвейеров, сигналы и 3D

В **AI Factory → Node graph** подключите выходы нескольких конвейеров к одному входу следующего конвейера. В его настройке **Тип объединения** выберите несколько входов или боковой вход; затем завершите линию роботом и паллетой. Изделия по очереди проходят на общий конвейер. Разделение потока пока не поддерживается.

В режиме сигнальных соединений перетащите выход датчика, кнопки, ПЛК или робота на вход питателя или робота; перетащите подключённый вход в сторону, чтобы отключить или перенаправить связь. Если у входа несколько источников, сначала выберите нужный выход. Подключённый питатель подаёт одно изделие на фронт сигнала. Визуальная программа робота расходует один сигнал на захват; выход робота может выдавать импульс после успешного размещения. В скриптах используйте `await robot.waitForSignal()`.

Инструменты **Move** и **Rotate** управляют объектом по X/Y/Z, включая высоту; привязка применяется и к повороту. Движение по земле и сферы сплайна сохранены. Геометрия наклонённого оборудования видна в 3D, но физические столкновения и некоторые операции рассчитываются с приближением вертикального положения.

### Архивы проектов

Используйте **Save project**, чтобы выбрать файл `.lcmx`, когда браузер поддерживает File System Access API, или **FILE → Export copy (.lcmx)**, чтобы скачать его. Сжатый архив включает встроенные пользовательские модели и worker-ресурсы. Браузеры без записи файловых дескрипторов скачивают копию вместо автосохранения в этот файл.
